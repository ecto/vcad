# 440 Hz tuning fork — reality-tower cornerstone 1

Laser-cut 304 stainless tuning fork whose pitch is *predicted from material
properties*, not copied from a fork drawing. Design rationale, model-error
budget, and oracle protocol: [docs/plans/tuning-fork.md](../../docs/plans/tuning-fork.md).

## The physics

In-plane cantilever tine mode: f₁ = (β₁²/2π)·(w/L²)·√(E/12ρ), β₁L = 1.8751.

| parameter | value |
|---|---|
| material | 304 stainless (E = 193 GPa, ρ = 8000 kg/m³) |
| stock | 0.25" (6.35 mm) plate |
| tine width w | 6 mm |
| tine length L | 104 mm |
| predicted f₁ | 440.0 Hz (ideal clamp; yoke compliance biases a few % flat) |
| out-of-plane mode | ≈ 466 Hz (above fundamental because t > w) |

## The fork family (pitch-law curve)

Three pitches from one law f = 0.5596·(w/L²)·√(E/12ρ), same material/profile —
a common cents offset across all three = yoke-compliance bias; a slope = E/ρ
error. DXFs generated by the same vcad pipeline:

| file | tine L | predicted f₁ | label |
|---|---|---|---|
| tuning-fork-g4-392hz.dxf | 110.2 mm | 392.0 Hz (G4) | `G4` engraved |
| tuning-fork-440hz.dxf | 104.0 mm | 440.0 Hz (A4) | `A4` engraved |
| tuning-fork-c5-523hz.dxf | 95.4 mm | 523.25 Hz (C5) | `C5` engraved |

All three carry a 14 mm lollipop tab at the handle end with a 5 mm hanging
hole (4.5 mm walls, clear of SCS's ~3.2 mm min feature at 0.25") and the
note name engraved vertically on the handle via the ENGRAVE layer
(single-stroke font, surface marking — select SCS's laser-marking service
at upload; skipping the service just leaves the handle blank). Handle/tab
geometry doesn't participate in the tine mode — pitch predictions are
unchanged.

Regenerate the DXFs with `node examples/tuning-fork/generate.mjs` (after
`VCAD_WASM_SKIP=1 npm run build --workspaces --if-present`).

## After it arrives

Strike a tine tip in the plane of the sheet, measure with a chromatic tuner,
and record predicted-vs-measured. The measurement is RT7 seed data for the
reality-tower spec (docs/reality-tower-spec.md). If flat (expected): file the
tine tips to raise pitch.
